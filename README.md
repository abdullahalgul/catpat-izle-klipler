# Çat Pat İngilizce · İzle klipleri

Çat Pat İngilizce uygulamasının **İzle** bölümünde oynatılan kısa film sahneleri.
Uygulama klipleri bu depodan (`raw.githubusercontent.com`) açar; uygulamanın içinde video yoktur.

Tüm sahneler ABD'de **kamu malı** (public domain) olan filmlerden kesilmiştir;
kaynak kopyalar Internet Archive'dandır:

| Film | Kaynak |
|---|---|
| Charade (1963) | https://archive.org/details/charade-1963-cary-grant-audrey-hepburn-comedy-mystery-romance-thriller-full-movie |
| My Man Godfrey (1936) | https://archive.org/details/MyManGodfrey1936 |
| His Girl Friday (1940) | https://archive.org/details/his_girl_friday_ipod |

Klipler `tools/content/cut_clips.py` ile üretilir (~360p, H.264 + AAC mono, faststart).
