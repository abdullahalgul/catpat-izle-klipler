# Çat Pat İngilizce · İzle klipleri

Çat Pat İngilizce uygulamasının **İzle** bölümünde oynatılan kısa film sahneleri.
Uygulama klipleri bu depodan (`raw.githubusercontent.com`) açar; uygulamanın içinde video yoktur.
Klipler `tools/content/cut_clips.py` ile üretilir (~360p, H.264 + AAC mono, faststart).

## Creative Commons filmler

Bu filmlerden kesilen klipler (`tears_*`, `cosmos_*`, `sprite_*`), aşağıdaki lisanslar altında
kısaltılmış (kesilmiş ve 360p'ye küçültülmüş) parçalardır. Klipler de aynı lisansla paylaşılır.

| Film | Hak sahibi | Lisans | Kaynak |
